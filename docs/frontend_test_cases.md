# RTS-AI-Platform 前端手工测试用例文档

> **版本**: v1.1  
> **更新日期**: 2026-06-04  
> **适用范围**: Godot 4.4.1 前端全部可交互功能（含本轮新增：合体/研究/升级/隐身/回放增强/APM/结算）  
> **种族缩写**: T=Terran, Z=Zerg, P=Protoss  

---

## 优先级定义

| 标记 | 含义 |
|------|------|
| **P0** | 冒烟级 — 阻塞基本游戏流程，必须通过 |
| **P1** | 核心功能 — 影响主要玩法体验 |
| **P2** | 辅助功能 — 视觉/便利性相关 |
| **P3** | 边界/极端场景 — 低频触发但需保障 |
